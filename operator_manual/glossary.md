# Glossary

Every term the handbook defines, in one sentence, with the section that explains it.

| Term | Meaning | Explained in |
|---|---|---|
| Acoustic echo cancellation | Subtracting the sound a device is playing from what its microphones hear, so it can listen while it talks. | [Voice Pipeline](05_voice_pipeline.md#key-definitions) |
| Active parameters | In a mixture-of-experts model, the subset of parameters used for each token, which sets speed while the total parameter count sets memory. | [LLMs on Apple Silicon](02_local_llm.md#reading-a-mac-spec-sheet) |
| Add-on | A Docker container that Home Assistant OS installs and manages for you, such as Piper or Music Assistant. | [Home Assistant](06_home_assistant_core.md#the-virtual-machine) |
| Agent loop | The pattern of calling the model, running any tool it asks for and calling it again, and returning its answer once it asks for none. | [Conversation Agent](04_conversation_agent.md#inside-the-loop) |
| Append mode | Opening a file so that every write lands at its current end, which lets a log be truncated underneath the program writing it. | [Operations](10_operations.md#the-report) |
| Assist pipeline | Home Assistant's chain of stages for one voice request (wake word, speech to text, intent matching or a conversation agent, text to speech), built by choosing one entity per stage. | [Home Assistant](06_home_assistant_core.md#assist-pipeline-and-intent-matcher) |
| Branch protection | A GitHub setting that makes `main` accept only merges of pull requests whose required checks passed and whose review threads are all resolved. | [Development](09_dev_environment.md#the-path-to-main) |
| Bridged networking | A virtual machine setting that puts the VM on the host's network with its own address, as if it were a separate computer. | [Home Assistant](06_home_assistant_core.md#the-virtual-machine) |
| Candidate | One model configuration the benchmark scores: an Ollama model tag or a set of hand-written answers, named by a key in `benchmark/config.yaml`. | [Benchmarking and Model Selection](01_llm_benchmark.md#questions-rubric-and-configuration) |
| Chat log | Home Assistant's record of one conversation's exchanges, handed to the conversation entity on every call. | [Conversation Agent](04_conversation_agent.md#two-layers-one-loop) |
| Compute | Arithmetic operations per second, which on a Mac scales with the number of GPU cores. | [LLMs on Apple Silicon](02_local_llm.md#prefill-and-decode) |
| Compute-bound | Limited by arithmetic throughput, as reading a long prompt is. | [LLMs on Apple Silicon](02_local_llm.md#prefill-and-decode) |
| Config flow | The wizard Home Assistant shows when you add an integration, which asks for its settings and checks them before saving. | [Home Assistant](06_home_assistant_core.md#the-custom-component) |
| Context window | The maximum number of tokens the model can see at once: the system prompt, the conversation, and tool results together. | [LLMs on Apple Silicon](02_local_llm.md#memory-cost) |
| Continue conversation | The `continue_conversation` flag on a reply, which tells Home Assistant to keep the microphone open for a follow-up without the wake word, and which the agent sets only after an ordinary answer (not after an empty reply or "Okay."), at most `max_follow_ups` times in a row, two by default. | [Conversation Agent](04_conversation_agent.md#two-layers-one-loop) |
| Conversation agent | The entity in an Assist pipeline that turns your text into a reply when no intent matches, which here is `conversation.studio_assistant` from the custom component. | [Conversation Agent](04_conversation_agent.md#two-layers-one-loop) |
| Conversation entity | The kind of Home Assistant entity a conversation agent is, which the Assist pipeline calls with your text and the chat log and expects a reply it can speak. | [Conversation Agent](04_conversation_agent.md#two-layers-one-loop) |
| Conversation id | The identifier Home Assistant uses to group exchanges into one conversation, so the agent receives the history on each call and stores nothing between calls. | [Conversation Agent](04_conversation_agent.md#inside-the-loop) |
| Cooldown | The minimum time between two automatic runs of the same action on the same target, 30 minutes for most actions and two hours for restarting the VM, so a broken part is not restarted at every five-minute check. | [Operations](10_operations.md#the-health-check) |
| Custom component | A Python package in Home Assistant's `custom_components/` folder that Home Assistant loads at startup, described by its `manifest.json`. | [Home Assistant](06_home_assistant_core.md#the-custom-component) |
| Decode | Writing the answer one token at a time, which is limited by memory bandwidth. | [LLMs on Apple Silicon](02_local_llm.md#prefill-and-decode) |
| Deploy plan | The ordered list of actions derived from the paths that changed between the running commit and the new one. | [Operations](10_operations.md#deploy-smoke-test-and-rollback) |
| Detached checkout | A checkout of a specific commit hash rather than a branch, so what is running is unambiguous and rolling back means checking out an older hash. | [Operations](10_operations.md#bootstrap) |
| DNS rebinding | A hostile name server answering a safety check with a public address and the connection a moment later with a private one, which the URL guard defeats by connecting to the address it checked. | [MCP Tool Server](03_web_search_mcp.md#the-url-guard) |
| Docker Desktop on macOS | An app that runs Linux containers inside a hidden Linux virtual machine, where they cannot see the GPU or receive the network's discovery packets. | [Hardware](08_hardware_and_deployment.md#three-places-to-run-a-service) |
| ELK | The Eclipse Layout Kernel, a layout engine Mermaid can use instead of its default, which keeps sibling groups in the order the source declares them. | [Development](09_dev_environment.md#the-manual) |
| Entity | A single thing with state in Home Assistant, such as a media player, a weather forecast, a speech-to-text engine, or a conversation agent. | [Home Assistant](06_home_assistant_core.md#assist-pipeline-and-intent-matcher) |
| ESPHome | A firmware framework for small Wi-Fi microcontrollers, configured in YAML and integrated with Home Assistant. | [Voice Pipeline](05_voice_pipeline.md#today-and-with-the-puck) |
| Exchange | One question you ask and the answer the assistant gives, however many model calls and tool rounds it takes. | [Conversation Agent](04_conversation_agent.md#one-exchange) |
| Exchange record | A trimmed copy of one exchange's transcript, without the page text, that the component posts to the tool server after each answer. | [Conversation Agent](04_conversation_agent.md#inside-the-loop) |
| Far-field microphones | Microphones and processing built to hear a voice across a room, through echoes and background noise, rather than next to the mouth. | [Voice Pipeline](05_voice_pipeline.md#today-and-with-the-puck) |
| FileVault | macOS disk encryption, which asks for a password before the operating system starts, so a Mac that must reboot unattended has it off. | [Hardware](08_hardware_and_deployment.md#coming-back-after-a-reboot) |
| Filler sentence | A short sentence such as "Let me work that out." that the agent speaks as soon as the model asks for its first tool, so you hear something within a second or two. | [Conversation Agent](04_conversation_agent.md#one-exchange) |
| Fuzzy matching | Tolerant string comparison, so "Radio Head" resolves to Radiohead. | [Music](07_music_spotify.md#the-path) |
| Gate | A pass-or-fail rule in the benchmark rubric whose failure zeroes the question, so a fluent fabrication cannot score well. | [Benchmarking and Model Selection](01_llm_benchmark.md#gates) |
| Git hook | A program git runs at a fixed moment, such as just before a commit is recorded, whose non-zero exit cancels the commit. | [Development](09_dev_environment.md#the-path-to-main) |
| Globally routable address | An IP address that belongs on the public internet, which rules out loopback, private-range, link-local, and multicast addresses. | [MCP Tool Server](03_web_search_mcp.md#the-url-guard) |
| Grounding | Giving the model retrieved text to base its answer on, so it summarises evidence instead of recalling from training. | [MCP Tool Server](03_web_search_mcp.md#one-tool-call-end-to-end) |
| Headless browser | A browser that runs without a window and is driven by a program, which is how mermaid-cli draws a diagram in Google Chrome. | [Development](09_dev_environment.md#the-manual) |
| Health snapshot | One health check's result (every probe's outcome, the memory figures, and the actions taken), written to `health.json` and appended to `health.jsonl`. | [Operations](10_operations.md#the-health-check) |
| Home Assistant | An open-source home automation platform, which here is the plumbing that talks to the voice devices, runs the speech pipeline, controls music, and hosts our agent. | [Home Assistant](06_home_assistant_core.md#how-it-works) |
| Home Assistant OS | A complete Linux operating system image that runs Home Assistant Core, the Supervisor, and add-ons as containers. | [Home Assistant](06_home_assistant_core.md#the-virtual-machine) |
| Idempotent | Safe to run again, because every step checks whether it is already done, so a script that fails halfway is simply rerun. | [Operations](10_operations.md#bootstrap) |
| Integration | Home Assistant's word for a connector to a device or service, such as Spotify, Sonos, or Met.no, which produces entities. | [Home Assistant](06_home_assistant_core.md#the-setup-script) |
| Intent | A structured meaning extracted from a sentence, such as `HassMediaSearchAndPlay(search_query="Radiohead", media_class="artist")`. | [Home Assistant](06_home_assistant_core.md#assist-pipeline-and-intent-matcher) |
| JSON Lines | A text format with one JSON object per line, used for the exchange records, the health history, the pipeline runs, and the benchmark results because adding a record is one appended line. | [Operations](10_operations.md#the-report) |
| JSON-RPC | A convention for calling named methods over any transport, in which the caller sends a JSON object with a method, its params, and an id, and the reply carries the same id. | [MCP Tool Server](03_web_search_mcp.md#one-tool-call-end-to-end) |
| Keep-alive | How long Ollama keeps a model's weights in memory after the last request: zero unloads at once, a duration such as `10m` unloads after that idle time, and `-1` keeps the model resident until Ollama stops. | [LLMs on Apple Silicon](02_local_llm.md#keeping-a-model-resident) |
| KeepAlive and StartInterval | Two launchd settings, where `KeepAlive` restarts a program whenever it exits, which suits a server, and `StartInterval` runs a program every N seconds and lets it exit, which suits a check. | [Hardware](08_hardware_and_deployment.md#three-places-to-run-a-service) |
| Kickstart | The command `launchctl kickstart -k`, which kills one launchd agent's program so that launchd starts it again at once. | [Operations](10_operations.md#the-health-check) |
| KV cache | The model's working memory for the current context, which costs memory in proportion to context length and saves recomputation. | [LLMs on Apple Silicon](02_local_llm.md#memory-cost) |
| Large language model (LLM) | A neural network that predicts the next token from everything before it, writes answers when run in a loop, and knows nothing after its training date. | [Introduction](index.md#key-definitions) |
| Last good commit | The commit hash that most recently passed the smoke test, kept in the file `last_good_ref` on the mini for a rollback to return to. | [Operations](10_operations.md#deploy-smoke-test-and-rollback) |
| launchd | macOS's service manager, which runs the program a plist file describes at login and keeps it alive or reruns it every N seconds. | [Hardware](08_hardware_and_deployment.md#three-places-to-run-a-service) |
| Line reference | A citation in a pull request description of the form `` `path:start-end` (`symbol`) `` that names the exact lines a reviewer should open. | [Development](09_dev_environment.md#the-pr-description) |
| LLM-as-judge | Using a strong model to grade another model's answer against a written rubric. | [Benchmarking and Model Selection](01_llm_benchmark.md#the-judge) |
| Lock file | A file that records every resolved dependency at one exact version with its hash, regenerated from the declared constraints; `uv.lock` is one. | [Development](09_dev_environment.md#the-environment) |
| Login item | An application macOS opens when the user logs in, listed under System Settings, General, Login Items. | [Hardware](08_hardware_and_deployment.md#coming-back-after-a-reboot) |
| Long-lived access token | A bearer token Home Assistant issues to one user for scripts, valid for years rather than minutes. | [Home Assistant](06_home_assistant_core.md#the-setup-script) |
| Main-content extraction | Turning a web page into the text a person came for, stripping navigation, ads, scripts, and legal text. | [MCP Tool Server](03_web_search_mcp.md#reading-the-pages) |
| Maintenance flag | A file the deploy creates before it changes anything, and while it exists the health check records but takes no action. | [Operations](10_operations.md#deploy-smoke-test-and-rollback) |
| MCP (Model Context Protocol) | A standard for exposing tools to a language model application over a network, in which a server declares each tool with a name, a description, and a JSON schema, and a client lists them, shows them to the model, and calls them when the model asks. | [MCP Tool Server](03_web_search_mcp.md#one-tool-call-end-to-end) |
| mDNS and zeroconf | How devices on a home network announce themselves by name without a central server. | [Home Assistant](06_home_assistant_core.md#the-virtual-machine) |
| Memory bandwidth | How many bytes per second move between unified memory and the chip, in GB/s. | [LLMs on Apple Silicon](02_local_llm.md#reading-a-mac-spec-sheet) |
| Memory-bandwidth-bound | Limited by how fast weights can be read from memory rather than by arithmetic, as writing tokens is. | [LLMs on Apple Silicon](02_local_llm.md#prefill-and-decode) |
| Mermaid | A text language for diagrams, in which a block such as `a["Ollama"] --> b["agent"]` becomes two boxes and an arrow when the site is built. | [Development](09_dev_environment.md#the-manual) |
| Metal and MLX | Apple's GPU programming interface and the machine learning framework built on it, which only native macOS processes can use to reach the GPU. | [Hardware](08_hardware_and_deployment.md#three-places-to-run-a-service) |
| Metasearch | A search engine, such as SearXNG, that queries other search engines and merges their results rather than crawling the web itself. | [MCP Tool Server](03_web_search_mcp.md#searxng-in-docker) |
| Mixture of experts (MoE) | A model whose layers are split into many "experts" with a small router picking a few per token, so it holds every expert in memory but runs nearly as fast as a much smaller model. | [LLMs on Apple Silicon](02_local_llm.md#reading-a-mac-spec-sheet) |
| Model tag | The name Ollama uses for one downloadable build of a model, such as `gemma4:e4b-it-qat`, whose part after the colon names the size and quantization. | [LLMs on Apple Silicon](02_local_llm.md#memory-cost) |
| Multicast | Sending a packet to a group address that every interested device listens to, which device discovery uses and Docker on macOS does not forward into containers. | [Home Assistant](06_home_assistant_core.md#the-virtual-machine) |
| Neural accelerators | Matrix-multiply units inside each GPU core of Apple's M5 and M6 chips, which speed up reading the prompt. | [Hardware](08_hardware_and_deployment.md#the-memory-budget) |
| OAuth | The login flow where you authorise an application to act on your account without giving it your password. | [Music](07_music_spotify.md#run-it-yourself) |
| Parameters | The learned numbers inside a model, counted in billions ("26B"), where more of them means more capability and more memory. | [LLMs on Apple Silicon](02_local_llm.md#memory-cost) |
| PCM audio | Uncompressed sound stored as a sequence of integer samples, described by a sample rate, a sample width, and a channel count. | [Voice Pipeline](05_voice_pipeline.md#key-definitions) |
| Phonemizer | A program that turns written text into the sequence of speech sounds a text-to-speech model pronounces. | [Voice Pipeline](05_voice_pipeline.md#packages-and-tools) |
| Prefill | Reading the whole prompt in one batch before the first token, which is limited by compute. | [LLMs on Apple Silicon](02_local_llm.md#prefill-and-decode) |
| Preview build | A reduced-precision build of a model whose 4-bit production build does not fit the prototype machine, so a high preview score is strong evidence for the production build and a low one only weak evidence against it. | [Benchmarking and Model Selection](01_llm_benchmark.md#questions-rubric-and-configuration) |
| Prompt injection | Text inside a tool result, here a web page, that is written like an instruction and that the model may follow because it cannot tell it apart from your question. | [MCP Tool Server](03_web_search_mcp.md#the-url-guard) |
| Provider and player | Music Assistant's two abstractions: a provider is where music comes from (Spotify), a player is where it goes (Sonos). | [Music](07_music_spotify.md#the-path) |
| Quantization | Storing model weights at 4 or 3 bits instead of 16, where 4-bit cuts memory about four times with a small quality loss and 3-bit cuts further with a noticeable one. | [LLMs on Apple Silicon](02_local_llm.md#memory-cost) |
| Question router | The step before the first model call that decides whether a question needs the web, the calculator, the forecast for home, or none of them. | [Conversation Agent](04_conversation_agent.md#the-question-router) |
| Reference sketch | Two or three sentences in the benchmark saying what a correct answer must contain, so the judge checks against it instead of working the problem itself. | [Benchmarking and Model Selection](01_llm_benchmark.md#questions-rubric-and-configuration) |
| rsync | A copy tool that compares source and destination and sends only the differences, the standard way to mirror a folder between two machines over SSH. | [Operations](10_operations.md#bootstrap) |
| SMB share | A folder served over SMB, the network file-sharing protocol that macOS and Windows speak natively. | [Home Assistant](06_home_assistant_core.md#the-virtual-machine) |
| Smoke test | The smallest end-to-end exercise that proves the system is alive: one question through Home Assistant, the conversation agent, the model, and the tools. | [Operations](10_operations.md#deploy-smoke-test-and-rollback) |
| Speech to text (STT) | A model that takes recorded audio and returns the text spoken in it. | [Voice Pipeline](05_voice_pipeline.md#speech-to-text) |
| Spotify Connect | Spotify's mechanism for controlling playback on another device from any client. | [Music](07_music_spotify.md#run-it-yourself) |
| SSH key | A secret file on the laptop and a matching public file on the Mac mini, which lets the mini check that the laptop holds the secret without the secret crossing the network. | [Operations](10_operations.md#key-definitions) |
| Static site generator | A program, such as MkDocs, that reads a folder of markdown files and writes plain HTML that any web server can host. | [Development](09_dev_environment.md#the-manual) |
| Streamable HTTP | MCP's current remote transport, in which every message is a POST to one endpoint and the server answers with a JSON body or a server-sent-events stream of `data:` lines. | [MCP Tool Server](03_web_search_mcp.md#key-definitions) |
| Streaming | Receiving the answer token by token as it is generated rather than waiting for the whole thing. | [Conversation Agent](04_conversation_agent.md#two-layers-one-loop) |
| Structured output | Asking the model for a reply that must match a JSON schema, which Ollama enforces during generation so the router always gets one of its allowed answers. | [Conversation Agent](04_conversation_agent.md#the-question-router) |
| Supervisor | The service inside Home Assistant OS that installs, starts, updates, and watches add-ons and applies operating-system updates. | [Home Assistant](06_home_assistant_core.md#the-setup-script) |
| Syntax tree | The structure Python builds from an expression before running anything, with each operator a node and the values it acts on as its children. | [MCP Tool Server](03_web_search_mcp.md#the-calculator-tools) |
| System prompt | Instructions placed before the conversation that the model treats as standing orders: who it is, how long to answer, and when to use tools. | [Conversation Agent](04_conversation_agent.md#inside-the-loop) |
| Temperature | A sampling setting where zero makes the model pick its most likely token every time and higher values add variety. | [Conversation Agent](04_conversation_agent.md#the-question-router) |
| Text to speech (TTS) | A model that takes text and returns audio of a voice speaking it. | [Voice Pipeline](05_voice_pipeline.md#text-to-speech) |
| Thinking mode | A setting on recent models that makes them write a hidden chain of reasoning before the answer, which helps hard problems and multiplies latency. | [LLMs on Apple Silicon](02_local_llm.md#prefill-and-decode) |
| Time to first audio | How long a text-to-speech server takes from receiving text to sending its first audio chunk. | [Voice Pipeline](05_voice_pipeline.md#run-it-yourself) |
| Time to first token | How long the model takes to read the prompt before it starts writing, which prefill sets and which grows with prompt length. | [LLMs on Apple Silicon](02_local_llm.md#prefill-and-decode) |
| Token | The unit a language model reads and writes, roughly a word fragment. | [Introduction](index.md#key-definitions) |
| Tokens per second | How fast the model writes once it has started, which decode sets and which keeps up with speech above about three to four. | [LLMs on Apple Silicon](02_local_llm.md#prefill-and-decode) |
| Tool calling | The model replying with a structured request to run a tool, such as `web_search(query="current federal funds rate")`, instead of with an answer. | [Conversation Agent](04_conversation_agent.md#inside-the-loop) |
| Tool round | One cycle of the agent loop in which the model asks for tools, the loop runs them, and the model is called again with the results, at most four per exchange. | [Conversation Agent](04_conversation_agent.md#inside-the-loop) |
| Tool schema | The JSON description of a tool's parameters, which the model reads to decide when to call the tool and how to form valid arguments. | [MCP Tool Server](03_web_search_mcp.md#one-tool-call-end-to-end) |
| Transcript | The record the agent loop returns at the end of an exchange: every message, every tool call with its result and timing, token counts, the route decision, the failure flags, and whether the reply stayed silent. | [Conversation Agent](04_conversation_agent.md#inside-the-loop) |
| Unified memory | One pool of memory shared by the CPU and GPU on Apple Silicon, whose size decides which models fit. | [LLMs on Apple Silicon](02_local_llm.md#memory-cost) |
| URL guard | The rule that the tool server connects only to public web addresses: an allowed scheme, no local names, every resolved address globally routable, and every redirect hop checked again. | [MCP Tool Server](03_web_search_mcp.md#the-url-guard) |
| UTM | A free virtualisation app for macOS that runs virtual machines on Apple's hypervisor. | [Home Assistant](06_home_assistant_core.md#the-virtual-machine) |
| Voice activity detection (VAD) | Deciding from the audio when a person has started and stopped speaking. | [Voice Pipeline](05_voice_pipeline.md#speech-to-text) |
| Wake word | A short phrase, such as "Hey Jarvis", that a tiny always-on model listens for before a device sends any audio anywhere. | [Voice Pipeline](05_voice_pipeline.md#today-and-with-the-puck) |
| Word budget | The soft cap on spoken words, 200 by default, past which speech stops at the end of the current sentence. | [Conversation Agent](04_conversation_agent.md#inside-the-loop) |
| Worktree | A second checkout of the same repository in its own folder, with its own branch and working files but the same history. | [Development](09_dev_environment.md#the-path-to-main) |
| Wyoming | A small line-based protocol that Home Assistant uses to talk to speech services over TCP, so a speech model can run on any machine it can reach by host and port. | [Voice Pipeline](05_voice_pipeline.md#one-question-end-to-end) |
