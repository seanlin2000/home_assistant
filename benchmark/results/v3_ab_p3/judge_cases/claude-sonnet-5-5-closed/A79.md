Reference sketch (what a correct answer must contain):
GPUs run thousands of simple cores in parallel with dedicated matrix units and very high memory bandwidth (HBM), and neural networks are mostly matrix multiplication; token-by-token generation is largely limited by memory bandwidth. NVIDIA's software stack (CUDA) is a large part of the advantage. An ASIC is a chip built for one kind of job (Google's TPU), more efficient but less flexible. Specialized inference processors go further for serving models, for example large on-chip SRAM instead of external memory (Groq), wafer-scale chips (Cerebras), or chips hard-wired for transformers (Etched). A specialized chip can win when the model architecture is stable and matches the chip, when the workload is high-volume and fixed, when latency per token matters most, or on cost or power per token; it loses when models change, when flexibility or training matters, or where software support is thin.

# Exchange 1

USER: Why are GPUs so effective at AI inference? Explain the differences between GPUs, ASICs, and specialized inference processors. Under what circumstances could a specialized chip outperform an NVIDIA GPU?

ASSISTANT: GPUs are good at AI inference because running a model is mostly huge amounts of matrix multiplication, which can be split into thousands of identical small tasks done in parallel. GPUs have thousands of cores, very fast memory, and mature software like CUDA, so they handle that well. Inference is often limited by memory bandwidth, because every generated token needs the model's weights read from memory, and GPUs have high-bandwidth memory for that. A CPU is a few powerful general cores. A GPU is many simpler parallel cores, still programmable. An ASIC is a chip designed for one job, such as Google's TPU or Amazon's Inferentia; it drops flexibility to save power and cost. Specialized inference processors, like those from Groq or Cerebras, rearrange memory itself, for example by keeping weights in on-chip SRAM, to cut the memory bottleneck. A specialized chip can beat an NVIDIA GPU when the workload is stable and large, so the design is worth the investment; when latency per token matters most; when energy or cost per token matters more than flexibility; or when the model fits the chip's memory design. Software support is the usual obstacle.
