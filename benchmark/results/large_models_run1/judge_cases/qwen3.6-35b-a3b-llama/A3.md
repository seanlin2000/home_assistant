# Exchange 1

USER: Someone says that because an MoE model only activates 4 billion parameters per token, a 4 GB GPU should be enough to run it. Is that correct? Explain exactly why or why not.

ASSISTANT: No, that is not correct. While the model only *activates* 4 billion parameters, the entire model must be loaded into the GPU's memory to function, which requires significantly more than 4 GB.

First, 4 billion parameters alone, even stored in the most compact 8-bit format, take up about 4 gigabytes just for the weights. You also need space for the 4 billion activations generated during processing, plus the memory for the optimizer states if you are training, or the key-value cache if you are running a language model. In practice, you would need a GPU with roughly 16 to 24 GB of memory to run a 4-billion-parameter MoE model comfortably.
