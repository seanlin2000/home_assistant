# Exchange 1

USER: Explain why VRAM capacity can matter more than raw GPU speed when choosing hardware for a local LLM. Answer in a way that would sound natural if spoken aloud in under 45 seconds.

ASSISTANT: A language model has to fit in memory before speed even matters. Each word it generates means reading through all of its weights, so they need to sit in the GPU's fast memory. If the model doesn't fit, the overflow spills into much slower system memory, and a fast GPU ends up waiting on it, often running five or ten times slower. A slower card with enough memory keeps everything in one place and stays usable. Memory capacity decides which models you can run at all, while speed only decides how fast they run once they fit. So when choosing hardware, buy enough memory first, then the fastest card you can afford.
