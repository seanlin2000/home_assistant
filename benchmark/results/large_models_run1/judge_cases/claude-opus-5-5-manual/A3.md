# Exchange 1

USER: Someone says that because an MoE model only activates 4 billion parameters per token, a 4 GB GPU should be enough to run it. Is that correct? Explain exactly why or why not.

ASSISTANT: No, that's not correct. The 4 billion active parameters tell you how much work happens per token, not how much memory the model needs. The router picks different experts for each token, so every expert has to be loaded and ready, and memory scales with the total parameter count, which might be 30 billion or more. Even the active part alone is about 2 gigabytes at 4-bit, plus the context cache and runtime overhead. What a 4 gigabyte GPU can do is hold the shared layers and the cache while the experts live in system RAM. That can work, and the low active count keeps it tolerably fast, but only if you have enough system RAM to hold the whole model, and it will be noticeably slower than running fully on the GPU.
