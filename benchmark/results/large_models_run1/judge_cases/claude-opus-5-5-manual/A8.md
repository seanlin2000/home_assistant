# Exchange 1

USER: For a personal AI assistant, compare these two designs: one large LLM handles every request, versus a smaller router that sends simple commands to deterministic tools and only uses a larger LLM for complex questions. Which would you recommend and why?

ASSISTANT: I'd recommend the router design. Most things you say to a home assistant, like timers, lights, weather, and simple facts, have exact answers that deterministic tools handle instantly and reliably, without the risk of a model inventing something. That makes those requests faster, cheaper to run, and predictable, and it frees the larger model to spend its time on questions that actually need reasoning. A single large model is simpler to build and handles odd phrasing gracefully, but it adds latency and some unpredictability to every request. The router's main risk is misclassifying a request, so make it fall back to the large model whenever it isn't confident.
