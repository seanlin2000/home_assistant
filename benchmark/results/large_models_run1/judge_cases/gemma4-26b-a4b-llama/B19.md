## Understanding the VRAM Requirements
Qwen3.8-27B has 27B dense (all active) + vision encoder (1152-dim, depth 27) parameters. At full precision (FP16), each parameter uses 2 bytes, so the model needs 54GB of VRAM just for the weights. At Q8 quantization, each parameter uses 1 byte (27GB). At Q4, roughly 0.5 bytes per parameter (14.85GB). On top of the model weights, you need ~1-2GB for the KV cache (conversation context), which grows with longer conversations. So a GPU with exactly 14.85GB won't be comfortable — budget 18GB+ for headroom.
