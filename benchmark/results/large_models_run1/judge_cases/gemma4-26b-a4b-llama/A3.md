# Exchange 1

USER: Someone says that because an MoE model only activates 4 billion parameters per token, a 4 GB GPU should be enough to run it. Is that correct? Explain exactly why or why not.

ASSISTANT: No, that is incorrect. While only four billion parameters are active during a single calculation, the entire model must be loaded into the GPU's memory to function.

If a model has a total of, say, forty-eight billion parameters, you would need enough VRAM to hold all forty-eight billion, not just the four billion used per token. Additionally, you have to account for the precision of the weights and the memory required for the KV cache, which stores context for the conversation. A four gigabyte card would be far too small for most Mixture of Experts models.
