USER: Why can a 16 GB GPU sometimes run an MoE model with 30 billion total parameters, but not necessarily a 30 billion parameter dense model? Explain the difference between active parameters and the memory required to store the model.

ASSISTANT: The reason comes down to the difference between how much space a model takes up on your disk and how much work your GPU actually has to do at any given moment.

To run any model, you must first fit all of its parameters into your video memory, so a thirty billion parameter model—whether it is dense or an MoE—will require roughly sixty gigabytes of VRAM just to hold the weights in sixteen-bit precision. This means that a sixteen gigabyte GPU actually cannot run either of these models in their full precision without using heavy compression techniques like quantization to shrink the size.

However, if we assume you have already used quantization to make the model fit, the distinction becomes about "active" parameters. In a dense model, every single one of those thirty billion parameters is used to process every single token you generate, which requires a massive amount of computational power and memory bandwidth. In a Mixture of Experts model, the total parameter count is much higher, but for any specific calculation, the model only activates a tiny fraction of those parameters—the "experts" relevant to that specific piece of data. This allows the model to have the vast knowledge of a huge system while only requiring the computational speed and active memory throughput of a much smaller one.
