### What is an AI inference chip?
An AI inference chip runs a trained model to produce answers, as opposed to training the model. Because generating each token requires reading the model's weights from memory, inference speed depends heavily on memory bandwidth, which is why Fractile, Groq, Cerebras and Etched compete on memory design.
