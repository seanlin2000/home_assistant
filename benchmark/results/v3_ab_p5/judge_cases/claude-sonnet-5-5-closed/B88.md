## What does ‘open AI model’ mean?
‘Open’ is a family of descriptions, not a guarantee. An open-weight release shares the final trained parameters of a model, which others can then fine-tune, adapt or deploy when the licence allows it. [4] An open-source AI system is a stronger claim. The Open Source Initiative's definition requires three elements under OSI-approved terms: data information detailed enough that a skilled person can build a substantially equivalent system, the complete source code used to train and run the system, and the model parameters. [1]
Before choosing a release, ask four questions: Can the exact weights be obtained? What licence applies? Which runtime and hardware can load the selected format? What evidence exists for the task that matters? ‘Open source’ is not a performance grade, a privacy guarantee or a promise that the model will fit on a laptop.

#### What hardware do I need to run a large open-source LLM?
Use a quantized version of the model (4-bit or 8-bit GGUF format via llama.cpp or Ollama) to reduce VRAM requirements by 4-8x with minimal quality loss. For larger models on consumer hardware, use model offloading or split layers across CPU and GPU RAM.

## gpt-oss (OpenAI)
OpenAI shipping open weights was the event nobody had on their 2025 card. gpt-oss-120b and gpt-oss-20b, released August 2025 under Apache 2.0, are the company’s first open-weight models since GPT-2. Both are MoE reasoning models with a 128K context and three configurable reasoning effort levels (low, medium, high), and both ship natively quantized in MXFP4.
## Muse Spark Open and Llama 4 (Meta)
Muse Spark Open is Meta’s first large open-weight release since Llama 4. It shares the `meta-models` Hugging Face organization with Muse Glimmer 30B, the dense model Meta published in August, but it ships under a license of its own. That organization carries Hugging Face’s verified badge under the name Meta Inc. The card credits Meta Superintelligence Labs and dates the release 15 October 2026. It is an 816B mixture-of-experts with 42B active, 256 experts routed 8 at a time across 62 layers, a 1M token context, and a 1.8B perception encoder, with text, image, video and audio input.
