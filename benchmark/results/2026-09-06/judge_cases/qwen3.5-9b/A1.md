# Turn 1

USER: Why can a 16 GB GPU sometimes run an MoE model with 30 billion total parameters, but not necessarily a 30 billion parameter dense model? Explain the difference between active parameters and the memory required to store the model.

ASSISTANT: A 16 GB GPU can run an MoE (Mixture of Experts) model with 30 billion total parameters because only a fraction of those parameters are used during any single forward pass—typically around one-third or less depending on the sparsity ratio—so the active memory footprint stays well within the GPU’s limits. In contrast, a dense model requires all 30 billion parameters to be loaded and kept in memory simultaneously, which for typical precision settings would demand roughly 60–120 GB of RAM just for weights alone, far exceeding what a 16 GB GPU can hold. The key distinction lies between total parameter count (which determines storage size) and active parameters (which determine runtime memory usage), and MoE architectures exploit this by activating only a subset of parameters per input.
