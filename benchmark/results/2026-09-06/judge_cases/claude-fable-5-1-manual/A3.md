# Turn 1

USER: Someone says that because an MoE model only activates 4 billion parameters per token, a 4 GB GPU should be enough to run it. Is that correct? Explain exactly why or why not.

ASSISTANT: No, that is not correct. Active parameters decide how much computation each token needs, not how much memory the model takes. Every token can be routed to different experts, so all of the experts have to be loaded and ready, which means memory is set by the total parameter count plus the working memory for the conversation. Four billion active parameters at four bits is about two gigabytes of weights read per token, which is why these models are fast, but the whole model is several times that size. A four gigabyte card could only work if the total model were tiny, or if most of the experts were parked in system memory and swapped in, which is slow and defeats the point.
