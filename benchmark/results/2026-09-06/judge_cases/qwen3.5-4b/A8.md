# Turn 1

USER: For a personal AI assistant, compare these two designs: one large LLM handles every request, versus a smaller router that sends simple commands to deterministic tools and only uses a larger LLM for complex questions. Which would you recommend and why?

ASSISTANT: The second design—a small router directing simple tasks to deterministic tools while reserving the large language model (LLM) for complex reasoning—is almost certainly the superior choice for a personal assistant. This architecture, often called "agent orchestration," drastically reduces latency, costs, and hallucinations because it avoids running an expensive LLM for every single query, such as checking a calendar or setting a timer.

Using deterministic tools for structured tasks ensures reliability; if you ask your assistant to add 5 to 7, the tool will always return 12, whereas an LLM might occasionally miscount. Furthermore, keeping the heavy LLM only for open-ended questions like "What should I make for dinner?" or "Help me plan a trip" preserves context and allows the model to actually think about your needs rather than just executing rigid commands.

The main caveat is that this system requires you to build the "glue" logic yourself—the code that decides when to call which tool—which demands some programming knowledge, whereas a single LLM design can be deployed via an API without building custom software infrastructure.
