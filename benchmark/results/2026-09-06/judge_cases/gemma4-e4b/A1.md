# Turn 1

USER: Why can a 16 GB GPU sometimes run an MoE model with 30 billion total parameters, but not necessarily a 30 billion parameter dense model? Explain the difference between active parameters and the memory required to store the model.

ASSISTANT: The main reason lies in how Mixture of Experts, or MoE, models utilize parameters compared to dense models. MoE models only activate a small subset of their total parameters for any given input, while a dense model must use all of its parameters for every single input.

Regarding memory, the difference is that even if a model has a vast number of total parameters, the memory required to *run* it at any given moment is determined by the number of parameters that are actually being used, which is much smaller in an MoE setup. The memory to *store* the model, however, must account for all of those parameters, whether they are active or not, which is why the total size is usually the limiting factor.
