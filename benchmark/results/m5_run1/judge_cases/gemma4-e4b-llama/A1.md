# Exchange 1

USER: Why can a 16 GB GPU sometimes run an MoE model with 30 billion total parameters, but not necessarily a 30 billion parameter dense model? Explain the difference between active parameters and the memory required to store the model.

ASSISTANT: The difference comes down to how the parameters are used during inference. A Mixture of Experts or MoE model only activates a small fraction of its total parameters for any given input, which keeps the active memory footprint low, whereas a dense model requires all of its parameters to be loaded into memory for every computation.

To elaborate, the memory required to store the model is determined by the total number of parameters, which is the full 30 billion in your example. However, with MoE, the model routes the input to only a few of its "expert" sub-networks, meaning only the parameters of those activated experts need to be loaded into the GPU's memory to perform the calculation. A dense model, conversely, uses every single one of its 30 billion parameters for every single calculation, which is what quickly exceeds the capacity of a 16 gigabyte GPU.
