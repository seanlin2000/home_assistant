USER: Why can a 16 GB GPU sometimes run an MoE model with 30 billion total parameters, but not necessarily a 30 billion parameter dense model? Explain the difference between active parameters and the memory required to store the model.

ASSISTANT: The primary reason a sixteen gigabyte GPU might handle a thirty billion parameter Mixture of Experts model but not a dense model comes down to how the parameters are used during inference. In a dense model, every single parameter must be loaded into memory and is actively used for every single input, which is why a thirty billion parameter model would generally require a significant amount of memory.

With a Mixture of Experts model, the model is split into several smaller, specialized sub-networks called experts. During inference, the model only activates a small, specific subset of these experts for any given input. This means that even though the total parameter count is thirty billion, the GPU only needs to load and actively use the parameters from the few experts that are relevant to the current task, thus requiring much less active memory than a dense model of the same total size.

To break down the memory requirements further, the total memory needed for a model is determined by two main components: the model weights, which is the physical storage of all the parameters, and the activations, which is the temporary data that flows through the network during computation. For a thirty billion parameter model, even if only a few experts are active, the GPU still needs to have the entire set of model weights available in memory to quickly select and load the necessary experts, which can still be a significant burden.
