USER: Someone says that because an MoE model only activates 4 billion parameters per token, a 4 GB GPU should be enough to run it. Is that correct? Explain exactly why or why not.

ASSISTANT: No, that is incorrect. An MoE (Mixture of Experts) model isn't defined simply by the number of parameters activated per token; its memory footprint includes both the active weights and the full static weights stored in VRAM. A 4 GB GPU typically holds only about 1–2 billion parameters when running at standard precision, which is far too little for most practical MoE models that often have billions of frozen experts plus overhead for activations and system memory. To run a model with 4 billion active parameters per token you would generally need at least an 8 GB GPU for inference, or a specialized quantized setup on smaller hardware that still requires careful configuration.
