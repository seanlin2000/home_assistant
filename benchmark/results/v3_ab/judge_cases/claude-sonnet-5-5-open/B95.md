ASSISTANT: The core idea is to put the language model on one machine in your home and keep everything else small. For one thousand dollars, I'd buy a mini PC or used desktop with a recent graphics card with twelve to sixteen gigabytes of memory, or a Mac mini with plenty of unified memory. These prices are my rough estimates, so check current costs. The components are a speech-to-text model such as Whisper, a local language model in the seven to fourteen billion parameter range served by llama.cpp or Ollama, a text-to-speech engine like Piper, Home Assistant for smart-home control, and a search tool that queries a web search service. A cheap microphone speaker array handles the room. The biggest limitations are that a small model reasons worse than cloud models, answers current-fact questions only through search, and can be slow if it is too large. Build in this order: first Home Assistant with simple voice control of devices, then speech in and out, then the language model for conversation, and last web search and polish. That way you get a useful assistant early.
