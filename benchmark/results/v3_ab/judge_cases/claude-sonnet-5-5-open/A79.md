Reference sketch (what a correct answer must contain):
GPUs run thousands of simple cores in parallel with dedicated matrix units and very high memory bandwidth (HBM), and neural networks are mostly matrix multiplication; token-by-token generation is largely limited by memory bandwidth. NVIDIA's software stack (CUDA) is a large part of the advantage. An ASIC is a chip built for one kind of job (Google's TPU), more efficient but less flexible. Specialized inference processors go further for serving models, for example large on-chip SRAM instead of external memory (Groq), wafer-scale chips (Cerebras), or chips hard-wired for transformers (Etched). A specialized chip can win when the model architecture is stable and matches the chip, when the workload is high-volume and fixed, when latency per token matters most, or on cost or power per token; it loses when models change, when flexibility or training matters, or where software support is thin.

# Exchange 1

USER: Why are GPUs so effective at AI inference? Explain the differences between GPUs, ASICs, and specialized inference processors. Under what circumstances could a specialized chip outperform an NVIDIA GPU?

ASSISTANT: GPUs are good at inference because running a neural network is mostly huge numbers of matrix multiplications, and a GPU has thousands of small cores built to do that math in parallel, plus very fast memory. Inference is often limited by how quickly weights can be read from memory, and GPU memory bandwidth is high. They also have mature software, which matters a lot. Now the differences. A GPU is flexible: it handles training, inference and many other workloads. An ASIC is a chip designed for one job, like Google's TPU, which trades flexibility for efficiency. A specialized inference processor, from companies like Groq or Cerebras, goes further by redesigning memory and data flow specifically for running models, for example keeping weights in on-chip memory to cut latency. A specialized chip can beat an Nvidia GPU when the workload is fixed and large, when you care about very low latency or energy per token, when the model architecture is stable, or when the volume is high enough to justify the software and deployment effort. The GPU's edge is flexibility and ecosystem, so for changing models and mixed workloads it usually still wins.
