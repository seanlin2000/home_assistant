Speech to text with a local model like Whisper, a language model served through llama.cpp or a similar server, text to speech like Piper, a wake word detector, and a small agent layer that lets the model call tools, including a web search tool through a privacy-friendly search API, and Home Assistant for controlling lights and devices. Web search sends queries outside your home, and smart-home devices that depend on a cloud will not be fully private. I would build in this order: first Home Assistant with voice for device control, since it works well with simple commands, then speech to text and text to speech, then the model for general questions, and last web search and long conversations.
