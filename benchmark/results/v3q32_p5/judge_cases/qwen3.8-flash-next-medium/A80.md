ASSISTANT: Quantizing means replacing each weight, normally stored as 16 or 32 bits of precision, with a much coarser representation, typically a small integer plus a shared scale factor, so the model keeps its structure but stores each number in far fewer bits.

For 70 billion weights, the arithmetic is simple: four bits each is half a byte, so 70 billion times 0.5 gives about 35 GB. Two bits each is a quarter byte, about 17.5 GB. Full 16-bit weights would need roughly 140 GB, so 4-bit cuts memory by about three-quarters.

The trade-offs: perplexity and reasoning quality drop, most visibly at 2 bits, where a plain scheme is often unusable without grouped scales or mixed precision. Quantized weights are slower to multiply but faster to load, and memory bandwidth usually dominates, so 4-bit models run well on a single GPU. Note these figures cover weights only; context cache and activations add more.
