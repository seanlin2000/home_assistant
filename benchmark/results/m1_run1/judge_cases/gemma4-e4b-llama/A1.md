# Exchange 1

USER: Why can a 16 GB GPU sometimes run an MoE model with 30 billion total parameters, but not necessarily a 30 billion parameter dense model? Explain the difference between active parameters and the memory required to store the model.

ASSISTANT: The key difference lies in how Mixture of Experts or MoE models utilize parameters compared to dense models. In an MoE model, only a small subset of the total parameters, the "active parameters," are engaged during any given computation, which allows a smaller GPU like one with sixteen gigabytes to handle a much larger total parameter count.

To elaborate on the memory aspect, the GPU needs to store the entire model, which includes all the parameters for every expert in the MoE architecture, even those that are not used for a specific input. The memory required to store all 30 billion parameters is the same for both the MoE and the dense model. However, the MoE model's computational load during inference is significantly reduced because the computation is only performed on the activated experts, not on all the parameters as in a dense model.
