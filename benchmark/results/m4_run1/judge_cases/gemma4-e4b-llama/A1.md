# Exchange 1

USER: Why can a 16 GB GPU sometimes run an MoE model with 30 billion total parameters, but not necessarily a 30 billion parameter dense model? Explain the difference between active parameters and the memory required to store the model.

ASSISTANT: I can certainly explain that for you. The main difference is that a Mixture of Experts model, or MoE, only activates a small fraction of its total parameters for any given input. This means the actual number of parameters being used in computation, the active parameters, is much smaller than the total parameter count.

The memory requirement for the model is determined by the need to store all of its parameters, regardless of whether they are active or not. A dense model requires all thirty billion parameters to be loaded into the GPU's memory to perform any computation, which might exceed sixteen gigabytes. In contrast, an MoE model keeps all thirty billion parameters in memory, but because only a few billion are active for inference, the computational load and the immediate memory pressure during the forward pass are lower, allowing it to fit within the sixteen gigabyte limit.
