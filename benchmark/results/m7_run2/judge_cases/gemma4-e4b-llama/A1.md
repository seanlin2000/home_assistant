# Exchange 1

USER: Why can a 16 GB GPU sometimes run an MoE model with 30 billion total parameters, but not necessarily a 30 billion parameter dense model? Explain the difference between active parameters and the memory required to store the model.

ASSISTANT: The primary reason for this difference lies in how Mixture of Experts or MoE models utilize parameters compared to dense models. An MoE model only activates a small subset of its total parameters, the active parameters, for any given token, which significantly reduces the computational load and memory footprint during inference. In contrast, a dense model must load and process all thirty billion parameters for every single token, which requires substantially more memory.

To elaborate on the memory requirement:

The memory needed to store the model is dictated by the total number of parameters, which for a thirty billion parameter model, is thirty billion parameters regardless of whether it is dense or MoE. This storage requirement is fixed.

However, the memory needed for *inference*—the actual running process—is where the difference is most apparent. For a dense model, the entire thirty billion parameters must be loaded into memory, and the computational graph must process all of them. For an MoE model, while the entire thirty billion parameters must still be stored in memory to be available, only the active parameters, which might be only a few billion, are actively loaded into the processing units for a specific input. This allows the model to have a vast parameter count for knowledge while keeping the computational and active memory demands low.
