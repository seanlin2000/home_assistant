## Why Prices Rose in 2026
The Raspberry Pi 5 originally launched in 2023 at $60 for 4GB and $80 for 8GB. The 16GB model arrived in January 2025 at $120. Those launch prices are no longer dependable references for a new purchase.
The result is especially striking for higher-memory boards. The 4GB model rose from $60 to $110, an increase of approximately 83%. The 8GB model rose from $80 to $175, or approximately 119%.
The 16GB increase is larger still. Its $385 current price is $265 higher than the original $120, a rise of approximately 221%. The current board costs about 3.2 times its introductory price.
Raspberry Pi describes the memory-price problem as temporary and says it hopes to reduce prices when market conditions improve. It has not established a guaranteed date for doing so. Buyers with flexible schedules may choose to wait, but current projects need to be budgeted at today’s prices.

Key specs include a PCIe 2.0 x1 interface, doubled USB and SD card bandwidth, and re-engineered MIPI lanes for faster storage, displays, and cameras.

- 2.4GHz quad-core Arm Cortex-A76 — 2–3× the CPU performance of Raspberry Pi 4, for a noticeably smoother desktop, browsing and code compiling

## Power and cooling

Raspberry Pi 5 draws more power than earlier models, so we recommend a 5V/5A (27W) USB-C PD power supply. For sustained workloads, use the Active Cooler or a case with a fan.

## FAQ

Will older versions of Raspberry Pi OS work with Raspberry Pi 5?No, it requires the latest Raspberry Pi OS. Older software like Raspbian or NOOBS isn’t supported, so you’ll need to flash a fresh SD card with the current version before booting up.

Will my power supply for Pi 4 work with the Pi 5 board?This board draws more power than the

Raspberry Pi 4, and an underpowered supply can cause issues. We recommend a high-quality 5V 5A USB-C power supply.

Does Raspberry Pi 5 need active cooling?

This new Pi is faster and more powerful than prior-generation Raspberry Pis, and like most general-purpose computers, it will perform best with active cooling. The Raspberry Pi Case for Pi 5, with its integrated fan, is one option. For configurations with a HAT, we recommend our HighPi Pro 5S Case with the official Active Cooler.

Will Raspberry Pi 5 fit my Raspberry Pi 4 case?

No. The board layout has changed, so Raspberry Pi 4 cases do not fit. Choose the official Raspberry Pi 5 case or our HighPi Pro 5S case.
