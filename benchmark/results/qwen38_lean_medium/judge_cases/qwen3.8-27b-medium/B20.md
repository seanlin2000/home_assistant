### Why is my local LLM so slow on a low-end PC?
The usual cause is memory bandwidth, not CPU speed: each token requires reading the whole model file from RAM, so speed is capped at memory bandwidth divided by file size. Check four things: a single RAM stick (one channel halves the ceiling), a model file too big for free RAM (swapping makes generation many times slower), a large context window (set `OLLAMA_CONTEXT_LENGTH=2048`), and whether the model runs on CPU or GPU (`ollama ps`). Then switch to a smaller model such as Qwen3 1.7B or Phi-4-mini at Q4_K_M.
### Can I run local RAG on a laptop with 2 GB of RAM?
Yes, for small document sets, if about 2 GB of RAM is free.
