ASSISTANT: Quantizing a model means replacing each weight, which is normally a full-precision floating-point number, with a smaller, lower-precision representation. A 70-billion parameter model stores 70 billion individual weights, so the memory question is straightforward arithmetic: multiply the parameter count by the number of bytes each weight occupies.

At 4-bit precision, each weight takes up a quarter of a byte, so 70 billion weights times a quarter byte comes out to about 35 gigabytes. At 2-bit, it drops to roughly 17.5 gigabytes. For comparison, if you kept the weights in standard 16-bit float, you would need 140 gigabytes, and at full 32-bit float, a whopping 280 gigabytes. So 4-bit gets you down to about a quarter of the 16-bit size, and 2-bit to an eighth.

The trade-off is accuracy. When you squeeze a number that once had many possible values into just 16 possible values at 4-bit, or just 4 values at 2-bit, you lose information. In practice this shows up as a small but measurable drop in the model's quality: it may be slightly worse at nuanced reasoning, more prone to occasional errors, or a bit more likely to hallucinate details. The drop is not catastrophic at 4-bit; modern quantization methods like GPTQ or AWQ are clever about it, using error-compensation tricks and sometimes keeping a few sensitive layers at higher precision to limit the damage. At 2-bit, though, the quality loss is usually significant and the model can become noticeably worse, though recent work like BitNet is pushing that boundary.

There are secondary benefits too. Smaller weights mean less memory bandwidth to move around, so inference gets faster and you can run the model on hardware that simply could not hold it at full precision. That is the main reason people quantize: it turns a model that needs a multi-hundred-gigabyte GPU setup into something that fits on a single consumer card, or even on a phone for smaller models. The practical sweet spot for a model this size has generally been 4-bit, where you keep most of the quality while fitting on a single 24-gigabyte graphics card with room to spare for the context.
