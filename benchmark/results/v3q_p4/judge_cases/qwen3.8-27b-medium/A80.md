ASSISTANT: Quantizing a model means replacing each weight's original floating-point number — typically a 16-bit float, in which case the weights of a 70-billion-parameter model take up about 140 gigabytes — with a much smaller integer representation, plus a shared scale factor that lets you decode the integers back into approximate floating-point values when the model runs.

At 4-bit precision, each weight gets 4 bits, which is half a byte, so the weights compress to about 35 gigabytes — a quarter of the original size. At 2-bit, each weight is only 2 bits, a quarter byte, bringing the weights down to roughly 17.5 gigabytes. In practice you add a little overhead for the scale and zero-point metadata, but modern group quantization keeps that to a small fraction, so those rounded figures hold up.

The trade-offs go like this. Fewer bits means each weight can only take a limited set of values, so information is lost and the model's answers drift a bit from the full-precision original. 4-bit is widely considered a near-lossless sweet spot for many models — methods like GPTQ, AWQ, and SmoothQuant handle the problem by quantizing in groups of weights and by protecting the few outlier weights that carry a lot of the signal, so quality drops are often in the single digits on benchmark scores, and in some cases imperceptible. 2-bit is much more aggressive: it's genuinely lossy, and quality degradation tends to become noticeable, especially on reasoning, coding, and long-context tasks. It's usually the territory where models start to fail at things they reliably did at full precision, so it's mostly a research and extreme-constraint option.

Beyond accuracy, there are practical downsides. Running a quantized model is often slower than it would be at full precision on modern hardware, because the CPU or GPU has to dequantize weights back to higher precision on the fly, so the speed benefit mostly shows up when you're memory-bound — that is, when the model fits in memory only because you quantized it. The memory win is exactly the point: 4-bit lets a 70-billion model run on a single high-end consumer GPU or a large workstation, and 2-bit makes it fit on a laptop with 32 gigabytes, even if the outputs are noticeably worse. And if you plan to fine-tune the model afterward, the compressed representation makes that harder and less effective, which is another reason people quantize only as a last step for deployment.
