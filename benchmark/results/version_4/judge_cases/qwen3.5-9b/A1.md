# Turn 1

USER: Why can a 16 GB GPU sometimes run an MoE model with 30 billion total parameters, but not necessarily a 30 billion parameter dense model? Explain the difference between active parameters and the memory required to store the model.

ASSISTANT: A 16 GB GPU can often handle a MoE (Mixture of Experts) model with 30 billion total parameters because only a fraction of those parameters are active during any single forward pass—say, if the routing mechanism activates just one out of three experts, you're really loading and computing on roughly 10 billion parameters. In contrast, a dense 30-billion-parameter model must load and process all 30 billion parameters simultaneously for every input. The key distinction is that MoE models separate memory storage (which does require holding the full 30 billion parameters) from computation (which only touches a subset), whereas dense models use both memory and compute on the entire parameter set at once. This means a 16 GB GPU might struggle to even store the full weights of a large dense model, let alone run it, while a MoE can fit within memory limits by activating only part of its parameters at a time.
