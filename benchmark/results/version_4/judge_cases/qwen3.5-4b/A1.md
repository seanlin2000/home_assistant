# Turn 1

USER: Why can a 16 GB GPU sometimes run an MoE model with 30 billion total parameters, but not necessarily a 30 billion parameter dense model? Explain the difference between active parameters and the memory required to store the model.

ASSISTANT: The key difference lies in how Memory-Oriented (MoE) models manage their parameters rather than storing them all at once. A MoE model has a total of 30 billion parameters across its entire architecture, but only a fraction—often just 1 to 2 billion—are "active" or loaded into the GPU's memory for any single inference step. This means that while the dense model requires 30 GB of VRAM to hold every parameter simultaneously, the MoE might only require 8–16 GB because it selects and processes a small subset of experts per token.

Essentially, the total parameter count represents the model's "potential" knowledge, but the active parameters represent what is actually being used at runtime. Since GPUs are limited by their physical memory (VRAM), a model can be trained on massive parameter counts using less VRAM if it only activates a portion of them during inference. This makes 16 GB sufficient for running a 30B MoE model, but insufficient for the same-sized dense model which requires full storage in memory.
