# Exchange 1

USER: Why can a 16 GB GPU sometimes run an MoE model with 30 billion total parameters, but not necessarily a 30 billion parameter dense model? Explain the difference between active parameters and the memory required to store the model.

ASSISTANT: The reason a sixteen gigabyte GPU can often run a Mixture of Experts model with thirty billion parameters, while struggling with a dense model of the same size, comes down to the difference between the total parameter count and the number of active parameters.

A dense model requires memory proportional to all thirty billion parameters because every single one must be loaded and accessible during inference. In contrast, a Mixture of Experts model only activates a small subset of its parameters for any given input token. For example, if the model is configured to use only two experts out of many, the GPU only needs to load and compute with the parameters for those two experts, which is significantly less than the full thirty billion.

The memory required to store the model is determined by the total size of all the parameters, while the memory *used* during the actual computation is determined by the number of active parameters and the necessary intermediate activations.
