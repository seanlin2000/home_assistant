I have a $1,000 hardware budget. Propose an architecture, explain the components, identify the biggest limitations, and prioritize what I should build first.

ASSISTANT: With a thousand dollars, I would build around a small always-on computer that runs everything in one box. Components: a mini PC or a used Mac mini with as much memory as you can afford, sixteen gigabytes at least, running a quantized model of about eight billion parameters through llama.cpp or Ollama. For voice, use Whisper for speech recognition, Piper for text to speech, and a wake word engine like openWakeWord, with Home Assistant tying it together through its voice pipeline. Add a USB speaker and microphone array for the room, around fifty to a hundred dollars. For web search, use a search API or a self-hosted search engine, exposed to the model as tools. Smart-home control goes through Home Assistant, which supports most devices locally. The biggest limitations are that a small model is less knowledgeable and less reliable with tools than cloud models, response time can be a few seconds, and web answers depend on outside services. Build first the voice loop with Home Assistant for lights, then add chat, then search.
