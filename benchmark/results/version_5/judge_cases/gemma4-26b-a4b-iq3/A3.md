# Turn 1

USER: Someone says that because an MoE model only activates 4 billion parameters per token, a 4 GB GPU should be enough to run it. Is that correct? Explain exactly why or why not.

ASSISTANT: No, that is not correct. While only four billion parameters are active during computation, the entire model—including all the inactive parameters—must be loaded into your GPU's memory to be accessible for those calculations.

If you are running a model with a total of, say, forty-eight billion parameters, you would need enough VRAM to hold the full weight of that model, not just the small fraction used for each individual token. Additionally, you have to account for the memory required to hold the "KV cache," which stores the context of your conversation, as well as the overhead from the software itself. A four gigabyte card would likely be far too small for any modern Mixture of Experts model.
