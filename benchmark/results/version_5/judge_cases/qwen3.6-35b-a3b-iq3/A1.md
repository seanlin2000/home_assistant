# Turn 1

USER: Why can a 16 GB GPU sometimes run an MoE model with 30 billion total parameters, but not necessarily a 30 billion parameter dense model? Explain the difference between active parameters and the memory required to store the model.

ASSISTANT: The main difference lies in how the model is structured and what actually needs to fit in your GPU memory. A dense model with 30 billion parameters requires all 30 billion weights to be loaded into memory at once because every parameter is active for every single input. In contrast, a Mixture of Experts model with the same total parameter count uses a sparse architecture. It splits its 30 billion parameters across many different "experts" and only activates a small subset of them—often just a few billion—for any given token. Since the weights of the inactive experts can remain in your system's slower RAM and only the active weights are loaded into the fast VRAM, you can run the MoE model on a 16 GB card that wouldn't be big enough for the dense version.

However, you still need enough VRAM to store the model's optimizer states, gradients, and the KV cache for your context, which is why the active parameter count must be significantly lower than the total to fit comfortably on consumer hardware.
