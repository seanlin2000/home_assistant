# Turn 1

USER: Why can a 16 GB GPU sometimes run an MoE model with 30 billion total parameters, but not necessarily a 30 billion parameter dense model? Explain the difference between active parameters and the memory required to store the model.

ASSISTANT: A 30‑billion‑parameter dense model needs to keep every weight in memory at once, so its 30 billion numbers have to fit in the GPU’s VRAM. A 30‑billion‑parameter MoE (Mixture‑of‑Experts) model, on the other hand, only loads into memory the subset of experts that are “active” for each token. If the routing layer activates, say, three experts out of a thousand, the GPU only has to hold the parameters of those three experts plus the shared layers, so the memory footprint can be well under 30 billion numbers. In short, the total parameter count tells you how much memory you’d need if you stored everything, but the active‑parameter count tells you how much you actually need to keep in VRAM while a particular batch is running.
