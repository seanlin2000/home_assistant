# Turn 1

USER: Someone says that because an MoE model only activates 4 billion parameters per token, a 4 GB GPU should be enough to run it. Is that correct? Explain exactly why or why not.

ASSISTANT: That is not correct because it overlooks how memory is allocated and managed during inference. While only a fraction of the parameters are "active" for any single calculation, the entire model—including all parameters across all experts—must typically be loaded into the GPU's VRAM to be accessible.

Because the GPU cannot instantly swap data from your system memory without a significant performance penalty, the 4 gigabytes of VRAM must be large enough to hold the total model size. In a Mixture of Experts model, even if only a few experts are engaged per token, the hardware still needs to hold the weights for all available experts in memory to ensure the right ones can be activated instantly. Unless the model is specifically partitioned across multiple GPUs or uses heavy quantization to shrink the total footprint, a 4 gigabyte card would only be sufficient if the total size of the entire model—not just the active portion—is under 4 gigabytes.
