# Turn 1

USER: Why can a 16 GB GPU sometimes run an MoE model with 30 billion total parameters, but not necessarily a 30 billion parameter dense model? Explain the difference between active parameters and the memory required to store the model.

ASSISTANT: Because memory is set by the total parameter count, but speed is set by the active count. A mixture of experts model with thirty billion total parameters still has to keep all thirty billion weights loaded, so at four bits it needs roughly fifteen to eighteen gigabytes, about the same as a dense thirty billion model, and both are a tight or impossible fit in sixteen gigabytes. The difference is what happens when it does not fit. A dense model touches every weight on every token, so anything spilled to system memory drags the whole thing to a crawl. The mixture of experts model only routes each token through a few experts, so the rarely used experts can sit in slower system memory without hurting much, and the small active set keeps it fast. So it is not that the mixture of experts needs less memory by nature, it is that it tolerates being partly outside the graphics card far better.
