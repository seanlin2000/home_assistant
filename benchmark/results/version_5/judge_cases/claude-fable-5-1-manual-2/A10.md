ASSISTANT: Because a model that does not fit in memory either will not load or spills into slower system memory and slows to a crawl, so capacity decides which models you can run at all, while GPU speed only decides how fast a model that already fits will go. A slower card with more memory can run a bigger, smarter model, or the same model at higher precision with a longer conversation history, and a faster card with less memory simply cannot. For a local assistant, running the right model matters more than shaving fractions of a second off a model that is too small.
