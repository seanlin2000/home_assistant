USER: Someone says that because an MoE model only activates 4 billion parameters per token, a 4 GB GPU should be enough to run it. Is that correct? Explain exactly why or why not.

ASSISTANT: No, that is not correct. Which experts fire changes from token to token, so every expert has to be loaded and ready, which means memory is set by the total parameter count plus the context cache, not by the four billion that are active. The four billion active is what keeps the compute and memory traffic per token small, so the model runs fast, but the model itself is several times larger; a four gigabyte card could not even hold four billion parameters at four-bit once you add context, let alone the whole expert pool. You could stream experts in from system memory, but then the card is a cache, not the home of the model, and the four gigabytes is not what is running it.
