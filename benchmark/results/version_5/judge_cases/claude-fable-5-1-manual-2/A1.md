# Turn 1

USER: Why can a 16 GB GPU sometimes run an MoE model with 30 billion total parameters, but not necessarily a 30 billion parameter dense model? Explain the difference between active parameters and the memory required to store the model.

ASSISTANT: Because memory is set by total parameters, not active ones. A thirty billion parameter model needs roughly fifteen to eighteen gigabytes at four-bit whether it is dense or a mixture of experts, so the MoE does not fit sixteen gigabytes by nature. What changes is that the MoE only runs a few experts per token, so each token needs far less compute and memory traffic, and that is what makes the practical trick work: you can park some experts in slower system memory and still get usable speed, because the offloaded experts are only touched occasionally. Do the same with a dense model and every weight is read on every token, so generation crawls. If the whole model has to sit in VRAM, both have the same problem and you would need a smaller quantization either way. Active parameters buy you speed, total parameters cost you memory.
