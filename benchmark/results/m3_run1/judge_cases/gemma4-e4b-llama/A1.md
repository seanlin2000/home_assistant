USER: Why can a 16 GB GPU sometimes run an MoE model with 30 billion total parameters, but not necessarily a 30 billion parameter dense model? Explain the difference between active parameters and the memory required to store the model.

ASSISTANT: The difference comes down to how the model utilizes its parameters during inference. A Mixture of Experts or MoE model only activates a small fraction of its total parameters for any given input, meaning the computational load and memory footprint during runtime are significantly lower than a dense model of the same total parameter count.

A dense model requires memory to store every single one of its thirty billion parameters, all of which must be loaded and potentially accessed during every calculation. In contrast, an MoE model, even with thirty billion total parameters, might only activate a few billion of those parameters for a single token. This means the active parameters—the ones actually involved in the computation for a specific input—are much fewer, allowing the model to fit within the limited memory of a sixteen gigabyte GPU.

To elaborate on the memory requirement, you need to consider that the model weights themselves take up storage, which is what the GPU memory is used for when loaded. The total number of parameters determines the size of the entire model file, while the number of active parameters determines the working set size—the portion of the model that is actively being used and needs to be held in fast memory during the forward pass.
