USER: Explain why VRAM capacity can matter more than raw GPU speed when choosing hardware for a local LLM. Answer in a way that would sound natural if spoken aloud in under 45 seconds.

ASSISTANT: VRAM is the bottleneck because the model's weights have to sit in memory while you run it, and if they don't fit, performance collapses. A fast GPU with too little VRAM can't load a large model at all, or is forced to offload parts of it to slow system RAM, which makes generation crawl from seconds per token to minutes. On the other hand, once the model fits comfortably, raw compute speed only matters for how quickly each token generates after that. So the practical rule is: buy enough VRAM to fit the model size and context window you actually want to run, then optimize for speed within that budget. A slower card with 24 gigabytes will usually beat a faster one with 12 when you're trying to run a 70-billion-parameter model locally.
