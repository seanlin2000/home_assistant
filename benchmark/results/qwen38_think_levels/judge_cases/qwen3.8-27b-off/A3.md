# Exchange 1

USER: Someone says that because an MoE model only activates 4 billion parameters per token, a 4 GB GPU should be enough to run it. Is that correct? Explain exactly why or why not.

ASSISTANT: No, that's not right. The "active parameters" number describes how much computation happens for each token, not how much memory the model needs. In a mixture of experts model, all the expert weights still have to sit in memory at once, because any of them can be selected for the next token. So a 40-billion-parameter MoE model with only 4 billion active per token still needs roughly 80 gigabytes at full precision, or about 20 to 25 gigabytes quantized to 4 bits, plus extra room for the KV cache and activations. A 4 gigabyte card could not hold the weights at all. The 4-billion-active figure is useful for estimating compute speed and power draw, but the memory requirement is set by total parameters.
