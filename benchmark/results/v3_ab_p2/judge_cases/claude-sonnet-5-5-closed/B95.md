## My Take: Buy Memory Now, Worry About Speed Later
The mistake most people make when buying local AI hardware in 2026 is optimising for speed when they should be optimising for capacity. Speed improves every generation. Apple’s M6 is 4.8x faster than M4 at LLM inference, and the M7 is already targeting 240 GB/s bandwidth. Nvidia ships a new GPU every twelve months. Software optimisations (better quantisation, speculative decoding, prompt caching) continuously improve tok/s on existing hardware.
