Reference sketch (what a correct answer must contain):
GPUs run thousands of simple cores in parallel with dedicated matrix units and very high memory bandwidth (HBM), and neural networks are mostly matrix multiplication; token-by-token generation is largely limited by memory bandwidth. NVIDIA's software stack (CUDA) is a large part of the advantage. An ASIC is a chip built for one kind of job (Google's TPU), more efficient but less flexible. Specialized inference processors go further for serving models, for example large on-chip SRAM instead of external memory (Groq), wafer-scale chips (Cerebras), or chips hard-wired for transformers (Etched). A specialized chip can win when the model architecture is stable and matches the chip, when the workload is high-volume and fixed, when latency per token matters most, or on cost or power per token; it loses when models change, when flexibility or training matters, or where software support is thin.

# Exchange 1

USER: Why are GPUs so effective at AI inference? Explain the differences between GPUs, ASICs, and specialized inference processors. Under what circumstances could a specialized chip outperform an NVIDIA GPU?

ASSISTANT: GPUs are good at inference because running a model is mostly huge amounts of matrix multiplication, which can be split into thousands of small identical operations done in parallel. GPUs have thousands of cores, special matrix units, and very fast memory, and that memory bandwidth matters a lot because generating each word means reading all the model weights. NVIDIA's software ecosystem, CUDA, also makes them easy to use. An ASIC is a chip built for one job, such as Google's TPU or Amazon's Inferentia. It drops the flexibility GPUs carry for graphics and general computing, so it can be cheaper and more power efficient for a fixed workload. Specialized inference processors go further. Groq and Cerebras, for example, put large amounts of fast on-chip memory next to the compute so weights do not have to travel from external memory, which cuts latency. A specialized chip can beat an NVIDIA GPU when the workload is stable and large, when you care about low latency or energy per word more than flexibility, or when the model fits the chip's memory design. The cost is less software support and less flexibility if models change.
