Diffusion

More steps is slower and usually cleaner. Guidance scale is how strongly the text and attributes steer the voice. Class temperature 0 picks the likeliest sound at each step; raise it for variety. Duration fixes the clip length, so a short value makes it speak faster.

Sampling

Speed is listed because Qwen3-TTS's generate() takes it, but mlx-audio 0.6.5 ignores it. Streaming context is how many earlier frames each streamed piece is decoded with; too few can click at the joins. A cloned voice always uses a repetition penalty of at least 1.5; mlx-audio raises it to stop the audio degenerating.
